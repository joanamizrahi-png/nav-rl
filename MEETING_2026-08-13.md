# Meeting notes — 2026-08-13

## This week in four results

1. **The RGB problem is solved, and inference is now ONE pass.**
   The semantic losses were dragging RGB (measured: SSIM 0.25–0.6 vs the
   pretrained model off-path). Added an RGB-preservation loss (second forward
   with our additions switched off = the pretrained model, pin RGB to it) +
   min-SNR loss weighting (the VDM paper's point, made explicit). Result: the
   finetune's own RGB now matches the pretrained model's fidelity to real
   footage (13.7 vs 13.2 dB / 18.7 vs 19.2 dB). So RGB + semantics come from
   a single pass, aligned by construction — the two-pass workaround is
   retired (kept as a paper ablation; we also built latent anchoring, which
   proved alignment-by-force works before we made it unnecessary).
   → show: 05_semantics/v10_v11_verdicts/ONEPASS_*.mp4

2. **Best semantic accuracy so far, via the learned reader.**
   The CE loss at ALL timesteps (your suggestion) quietly trained a strong
   per-pixel reader; using it as the decoder instead of nearest-palette-color:
   **79.9% / 80.6%** held-out (v9 was 78.8 / 69.9), vegetation-vs-grass
   confusion largely resolved. Every ingredient was ablated individually:
   all-timestep CE +4.4, preservation at 0.3 (not 1.0) +2.4, min-SNR +6.1
   alone, bigger reader head +1.1. v11 (winners composed) trained overnight,
   grades landing today — targets ≥82 / ≥80.
   → show: v10_v11_verdicts/READER_*.mp4 and ABLATIONS_*.mp4

3. **Heading made visible (your rollout-video item) — and it caught something.**
   Eval videos now draw the heading arrow + a goal compass. Building the
   "given a pose, is the image direction correct" probe surfaced a suspected
   yaw mirror on the training scene: pose math and rendered image may
   disagree on left/right. Verdict lands today from sweep videos (continuous
   ±30° turn — direction of content flow is unambiguous). Important
   framing: the sim is self-consistent, so all policy results stand; this
   only matters (critically) for real-robot transfer — exactly the kind of
   bug we want dead before deployment.
   → show: 06_diagnostics/pose_direction_*.png + yaw_sweep videos,
     04_rl_policy/rollouts_with_heading_overlay/

4. **Literature check on our fixes (deep-research sweep, cited report):**
   the 2024–26 co-generation papers (UDPDiff, IDC-Net, GeoVideo, SP4D,
   One4D) manage RGB via training recipes or hard isolation — none uses a
   preservation loss, none measures per-pixel drift vs the base model, and
   train-time anchoring has no prior art. Three candidate novelty claims.
