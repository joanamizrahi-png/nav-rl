## 1. The world model works — proven, not asserted

- **Expert replay**: the environment driven along the real robot's recorded path
  renders a first-person walk nearly identical to the original video, with the
  reward staying positive on the real path (+0.96 typical).
  → `inference_runs/replays/replay_v3_vs_original.mp4` (side-by-side)
- This test caught and led to fixing **two real geometry bugs** (a left/right
  handedness mirror in pose composition; renders pinned to the wrong timestamp in
  dynamic scenes) — the sanity-check layer doing its job before results existed.

## 2. Geometric accuracy — the three questions, answered with numbers

**"Can the next step be projected into the current image well?"** Yes: the robot's
actual future position projects onto the path it then walked (videos, 3 scenes+).
Flat-ground assumption error: median 3–11 px vs a ~100 px footprint; worst case
53 px on the hilliest scene. → `outputs/projection_test/*.mp4`

**"Can we know the ground shape?"** Yes, from the Gaussians themselves: local
ground = 40th percentile of splat heights within 0.75 m (setting chosen by a
31-scene sweep) matches the trajectory-derived true ground with **median error
~2.7 cm** (1.7 cm on flat trails, ~5 cm on hilly parks). Going above p40 fails
measurably — the estimator climbs onto creek-bank vegetation (visible in the
creek_01 p40-vs-p50 plots). → `outputs/scene_clouds/ground/` (sweep + per-scene)

**Calibration honesty**: our metric scale had been anchored to a guessed camera
height (0.6 m). Questioning it led to the RUGD paper's documented value
(viewpoint < 25 cm; we use 0.25 m). Independent check: at the old scale the
implied robot speed exceeded the platform's top speed; at the corrected scale it
is 0.18–0.47 m/s (top speed 1.0). All artifacts regenerated at the corrected
scale. Residual: paper says "<25 cm" (±~20% scale uncertainty); our own future
recordings (lidar + odometry) convert this from assumed to measured.

## 3. Semantics — three sources, three roles (current design)

| Source | Where used | Why |
|---|---|---|
| SAM3 fused onto the 3D Gaussians | RL reward (re-projected per step) | available at any pose; deploy-consistent; fast |
| RUGD human ground truth | trains the semantic diffuser; evaluation yardstick | quality; but nonexistent at deployment |
| Semantic diffuser (v7) | not in RL yet — planned reward upgrade | corrects SAM3's systematic errors toward GT |

v7 result: trained against dense GT targets, the diffuser now outputs clean class
regions and **corrects SAM3's errors** (e.g., forest labeled "building" by SAM3 →
"tree" by v7, matching GT). → `inference_runs/hint_vs_gt_vs_v7.mp4`,
`compare_v6_v7_semantic.mp4`, legend at `outputs/legend.png`.

**Open design question (raised by Joana, unresolved on purpose):** when the
diffuser feeds the reward, which configuration wins?
(a) SAM3 run on the generated RGB — *perfectly consistent with the observation*,
but SAM3-grade labels; (b) one joint diffusion pass producing both the observed
RGB and its semantics — consistency built in, GT-grade labels, slightly softer
RGB; (c) split passes — best RGB and labels, but they can disagree in inpainted
regions. Consistency-vs-quality is measurable and becomes one of our ablations.
A related guard under discussion: labels on geometry-confirmed regions get full
trust; labels on inpainted (invented) regions get discounted — degree TBD
empirically so the discount doesn't recreate the void problem.

## 4. RL — first run, honest diagnosis, second run in progress

- Loop performance: ~46 env-steps/s (rasterized observations); 200k-step training
  in ~70 min. Compute is not the bottleneck at this stage.
- **Run 1 (200k)**: return rose then collapsed; policy circles in place. Diagnosis:
  the reward *scored* the good path correctly but *guided* nowhere — off the
  narrow corridor everything was void → −5, so any exploration was punished and
  spinning was rational. Observations also go black off the reconstructed
  manifold (rasterizer-only), so a lost policy is blind.
- **Run 2 (launched today)**: reward reshaped from the diagnosis — void split
  from obstacles (−0.3 vs −5), collision 1.0 on real obstacles only, goal pull
  1.5, spin tax, ~3–4 m goals, random spawns along the real trajectory. Unit
  check: mixed grass/unknown footprint −2.09 → +0.27.
- **Observations**: rasterized for now (deliberate staging). Decision made:
  diffused observations are the endpoint; the mechanism (pose-cache vs.
  short-batch vs. every-N-th) is next week's design + build. Raster-vs-diffused
  is a planned ablation.
